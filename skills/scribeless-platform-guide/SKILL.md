# Scribeless Platform Guide

## Workflow

1. Identify the user's goal:
   - create template
   - create one-off campaign
   - create recurring campaign or flow
   - upload recipients
   - create or find API key
   - review dashboard or QR scans
   - manage account/team settings
2. If browser access is available, inspect the current platform page before giving step-specific guidance.
3. Keep instructions tied to visible product labels.
4. Ask for confirmation before actions that create, send, checkout, delete, publish, or modify live account data.
5. If the user is blocked by missing account access, payment setup, API key visibility, or an empty template/campaign list, explain the next visible action and what information they need.

## Core Platform Paths

- Dashboard: `https://platform.scribeless.co/`
- Templates: `https://platform.scribeless.co/templates`
- Create template: `https://platform.scribeless.co/templates/create`
- One-off campaigns: `https://platform.scribeless.co/campaigns`
- Create one-off campaign: `https://platform.scribeless.co/campaigns-create`
- Recurring campaigns: `https://platform.scribeless.co/recurring-campaigns`
- Flows: `https://platform.scribeless.co/flows`
- Settings: `https://platform.scribeless.co/settings`
- API keys: Settings > Organization > API Keys
- Help Center: `https://help.scribeless.co/en/`
- API docs: `https://docs.scribeless.co/`

## Guidance Rules

- Do not invent hidden menu labels. Use visible labels from the page or Help Center.
- If a user asks for a live browser walkthrough, follow observe, act, observe.
- Never expose, copy, or store API keys in the answer.
- Warn that API keys are shown once after creation if the platform says so.
- Do not submit a campaign, turn on an automation, or start checkout without explicit user confirmation.
