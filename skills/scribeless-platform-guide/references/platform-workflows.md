# Platform Workflows

## Create a Template

1. Open Templates.
2. Choose Create template.
3. Enter template name.
4. Choose product and size.
5. Create the template.
6. Add copy, images, variables, and optional Smart QR code.
7. Preview both note/card and envelope where relevant.
8. Publish or save only when the user confirms.

## Create a One-Off Campaign

1. Open Create one-off campaign.
2. Enter campaign name.
3. Select a template.
4. Choose shipping method:
   - Send for you, with a local stamp
   - Shipped in bulk to your address
5. Configure return address and envelope options when visible.
6. Upload recipients or skip for later.
7. Review warnings before marking recipients ready or checking out.

## Prepare Recipients

1. Confirm campaign and template variables.
2. Prepare required name and address fields.
3. Map extra personalization fields into variables.
4. Validate warnings before upload.
5. Upload and review recipient statuses.

## Find API Keys

1. Open Settings.
2. Open Organization.
3. Open API Keys.
4. Create a new key only when ready to store it securely.
5. Never paste the secret key into chat unless the user explicitly decides to and understands the risk.

## Review Dashboard and QR Scans

1. Open Dashboard.
2. Review mailers sent, processing recipients, QR scans, and event log.
3. Use Download scans when the user needs analysis outside the platform.
